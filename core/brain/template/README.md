# Your Brain

This content tree is the seed of your PyRun Brain. Edit identity notes and the
taxonomy in CLAUDE.md first. The console stores each change as an immutable
revision; imports and exports use UTF-8 ZIP archives. Git is not required.

Knowledge notes hold distilled ideas and provenance. Raw source text belongs in
raw/. Grants control which scripts, plugins, agents and tokens may read or
propose. Every feed requires human approval. INDEX.md is generated per tier.
