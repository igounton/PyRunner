# raw/

Full source text: transcripts, post exports, long thoughts — or pointer
files saying where the original lives.

**This folder is never browsed.** Agents reach a raw file only through a
link in a note or card that they were already allowed to read, and the raw
file inherits that note's visibility. That is why it can hold long,
unfiltered material without widening what any consumer can see.

Use it when a note needs depth behind it: the note carries the distilled
claim and the VERBATIM quote, `raw/` carries the whole transcript for the
rare task that needs the full thing.

Naming: match the `source:` id where you can — `yt-2026-07-some-video.md`
next to a note whose `source: yt-2026-07-some-video`.
